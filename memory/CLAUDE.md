# CLAUDE.md

## Change log

Append an entry to `CHANGELOG.md` in the same turn any requested change is made
— don't wait to be reminded, don't batch entries for later.

- Log changes that were *requested*. Reads, reviews, and answers to questions
  are not changes and don't belong there.
- One line per change, under a dated heading:
  `- **<area>** — <what changed>. <why>.`
- Write the entry after the change succeeds, so the log never claims work that
  failed. If something was only partly done, say so.
